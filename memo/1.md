# tob

```javascript
const o = tob({
    name: String,
    age: Number,
    big: BigInt,
    is: Boolean,
    fn: Function,
    obj: Object,
    sym: Symbol,
    class: Map,
    items: [Array, Number],
    nest: {
        group: {
            name: String,
            obj: Object,
        },
    },

```

# 追加情報

配列の場合、`[Array, Number]`のようにすることで要素の型がすべてNumberであることを示す。

文字列の場合、`[Striing, /^some*$/g]`のように正規表現を示すことでtest()で判定できるようにする。または第一要素が正規表現なら自動的に`String`であると判断できるため省略可能。

# 違反時の対応

* `false`を返却する
* 例外を投げる
* 例外インスタンスの配列を返す（複数のエラーがあっても全部網羅できる）

違反時のタイミング。

* 個別変数に代入した時
* 定義関数に全体変数を引数で渡して呼び出され違反が存在した時


```
o.v = 9; // 例外発生
```
```
o.v = 9;
const msgs = tob.verify(o); // {name:[RangeError('0〜3までの範囲内であるべきです。')]}
```

# 拡張型

```
const o = tob({
    i: [Integer, v=>Number.isSafeInteger(v)]
    i: tob.i, // Integer Safe
    u: tob.u, // Unsigned Integer Safe
    u8: tob.u8,
    i8: tob.i8,
    f: tob.f, // Finite Safe
});
```

拡張型なら続けてバリデーションも簡易指定できたほうが嬉しい。

```
const o = tob({
    i: [Integer, v=>Number.isSafeInteger(v)]
    i: tob.i.rng(min,max), // Integer Safe
    u: tob.u.rng(min,max), // Unsigned Integer Safe
    u8: tob.u8,
    i8: tob.i8,
    f: tob.f, // Finite Safe
});
```

更に複雑なバリデーションを実装したい時。

```
const o = tob({
    i: [tob.i.rng(min,max).even, 0], // Integer Safe
    i: [tob.i.rng(min,max), 0, v=>0===v%2], // Integer Safe
    i: [tob.i.even, 0, v=>(min<=v && v<=max)], // Integer Safe
    i: [Number, 0, v=>Number.isSafeInteger(v) && 0===v%2 && (min<=v && v<=max)], // Integer Safe
    i: [Number.isSafeInteger, 0, v=>0===v%2 && (min<=v && v<=max)], // Integer Safe
});
```

    ary: [], // Array
    // fn: ()=>{}, // Function

    i: [Number.isSafeInteger, 0, v=>0===v%2 && (min<=v && v<=max)], // Integer Safe

Objectは他にもObject.create(null)やObject.create({})やObject.defineProperty()やnew Boolean()などから生成されるものもある。だがそれらは対象外とする。NoneSupport Object|Type という扱いにする。
