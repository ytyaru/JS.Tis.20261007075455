# tis

tis自身を関数オブジェクトにする。汎用性の高い関数にする。子関数を持たせることで`tis.int(0)`のようにも呼び出せる。

```
tis(値, 型); // 値は型であるか否か
```
```
tis(v, Boolean|Number|String|BigInt|Symbol|Object|Array|Function|他コンストラクタ関数)
tis(v, false|0|''|0n|{}|[]|Date等)
```
```
tis(v, Array, Boolean)
tis(v, [false]);
```
```
tis(v, Object)
tis(v, {k:Boolean, l:{m:Number}});
tis(v, {k:false, l:{m:0}});
```

型指定は組込コンストラクタ関数または定数のいずれかで指定できる。

組込コンストラクタ関数|定数
----------------------|----
Boolan|`false`
Number.isSafeInteger|`0`
Number.isFinite|`.1`
String|`''`
BigInt|`0n`
Symbol|`Symbol()`
Object|`{}`
Array|`[]`
Function|-
他コンストラクタ関数|`Date`等（クラスでなくインスタンスであることを確認する。）

```
tis(v,0);
tis.int(v);
```



# 型ごとにバリデーション用拡張引数も用意する？

## 数

```
// 複合。順序と型で区別する
tis.fin(v, min, max, [3.1, 4.2, 9.3], v=>true)
tis.int(v, min, max, [3, 4, 9], v=>true)
tis.big(v, min, max, [3n, 4n, 9n], v=>true)
```
```
// 範囲
tis.fin(v, min, max)
tis.int(v, min, max)
tis.big(v, min, max)
```
```
// 候補
tis.fin(v, [3.1, 4.2, 9.3])
tis.int(v, [3, 4, 9])
tis.big(v, [3n, 4n, 9n])
```
```
// 任意関数（真偽値、文字列、数（エラーコード）を返却する）
tis.fin(v, v=>true)
tis.int(v, v=>true)
tis.big(v, v=>true)

tis.fin(v, v=>v ? '' : 'エラー')
tis.int(v, v=>v ? '' : 'エラー')
tis.big(v, v=>v ? '' : 'エラー')

// Number型。0が正常、1以上の整数が異常。負数や少数は対象外。
tis.fin(v, v=>v ? 0 : 9)
tis.int(v, v=>v ? 0 : 9)
tis.big(v, v=>v ? 0 : 9)
```

## String

```
tis.str(v, /^some*$/g)
tis.str(v, '候補1', '候補2', ...) // 可変長引数...args 全て文字列なら候補である
tis.str(v, min:0, max:0) // Graphemes単位 Intl.Segment()
tis.str(v, {len:{unit:'CodeUnit/CodePoint/Graphemes/Word/Phrase/Sentence', min:0, max:0}})
tis.str(v, v=>true);
```
```
tis.str(v, min, max, /^some*$/g)
tis.str(v, min, max, '候補1', '候補2', ...)
tis.str(v, {
    reg: /^some*$/g,
    cands: ['候補1', '候補2', ...],
    len:{
        unit:'CodeUnit/CodePoint/Graphemes/Word/Phrase/Sentence',
        min:0, max:0
    },
    fns: [
        v=>true, // 返却型＝真偽値
        v=>v ? '' : '文字列は空です。1字以上入れてください。', // 返却型＝文字列（エラー時のみ1字以上の文字列を返す）
        v=>v ? 0 : 1,    // Number.isSafeInteger。エラーコード。0は正常、1以上の整数が異常。負数は対象外。
        v=>v ? 0 : [3, 'X', 'Y', 'Z'], // 配列返却時はエラーメッセージを動的生成する。配列の0番目はエラーコード。以降はエラーメッセージ生成用引数。
    ],
    msg: [// ここだけ別の文字列配列にすることで多言語化できる
        '1番のエラーメッセージです。', 
        '2番のエラーメッセージです。', 
        (...args)=>`3番のエラーメッセージ。argsを利用して動的にメッセージを生成する: ${...args}`,
    ],
    msg: [// 但しギチギチに詰めるとエラーの追加や削除などで番号が変わってしまいコード修正箇所が膨大になる。そこでnew Map([[0x00, 'message'],[...],...])のようにすることも可能にする。
        [0x0001, '想定外のエラーです。'],
        [0x0010, 'メモリ不足です。'], // 番号に敢えて欠番を作ることである程度の増減に耐えられるようにする
        [0x0020, (...args)=>`${args}`], // 番号に敢えて欠番を作ることである程度の増減に耐えられるようにする
    ],
})
```

関数の戻り値の型に応じて、もし例外発生させるなら以下のような型とメッセージにする。尚、必ずしも例外発生させるとは限らない。メッセージだけ取得したい場合もあるから。

```
v=>true                             ValidationError: コード内容(v=>true)
v=>v ? '' : '文字列',               ValidationError: 文字列
```

引数でなくメソッドチェーンで指定させるべきか？

```
// メソッドチェーンで指定させる？
tis.str(v).len(min,max) // len.gの省略形
tis.str(v).len.cu(min,max) // CodeUnit
tis.str(v).len.cp(min,max) // CodePoint
tis.str(v).len.g(min,max)  // Graphemes
tis.str(v).len.w(min,max)  // Word
tis.str(v).len.p(min,max)  // Phrase
tis.str(v).len.s(min,max)  // Sentence
tis.str(v).reg(/^/) // 正規表現
tis.str(v).cands('候補1', '候補2', ...) // 候補
tis.str(v).fns(v=>true, v=>v ? '' : 'エラー', ...) // バリデート関数
tis.str(v).msg(['','',...]) // バリデート関数でNumberを返却する時に対応するエラーメッセージ（連番版）
tis.str(v).msg([[0x1,''],[0xF,''],...]) // バリデート関数でNumberを返却する時に対応するエラーメッセージ（歯抜け対応版）
```
```
tis.str(v).len.g(min.max).reg(/^/).cands('候補1', '候補2', ...)
```

# バリデータ生成APIにすべきか？

もはや型判定ではない。値判定または型から値判定までを含めた専用型生成器である。

generateValidatorだ。

```
vor.int.rng(min, max).fn(v=>true, v=>v ? 0 : 1).msg(['1番のエラーメッセージ']);
vor.str(min, max, /^/, ['候補1', '候補2', ...])
```

```
const vorAge = vor.int.rng(min, max).fn(v=>true, v=>v ? 0 : 1).msg(['1番のエラーメッセージ']);
const msgs = vorAge(v); // 正常なら[], 異常ならエラーメッセージ文字列の配列
```

`array?.length === 0`

せめて`Object.define(Array.prototype, 'isEmpty', {get(){return 0===this.length}})`のようなAPIが欲しい。表記ゆれをなるだけ減らすために。尤もnullだのundefinedだので空を示すという方法論もあるためそれはどうしようもないが。まさかグローバル関数で`isEmptyArray(v){...}`のようなものを作るのもどうかと思うし。
